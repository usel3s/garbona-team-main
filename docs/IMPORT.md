# Публикация документации

Единственная актуальная пользовательская документация находится на
[https://garbona.cc/docs/](https://garbona.cc/docs/).

Исходные тексты в этом каталоге сохранены как внутренний архив. Они не являются
отдельной опубликованной базой и не должны использоваться для создания второго
пользовательского каталога руководств.

Публичное содержимое, навигация и поиск поддерживаются в `docs-site/` и
отдаются приложением по маршруту `/docs/`.

# Garbona

Мы рады, что вы здесь **в начале** — в точке, где формируется команда **Garbona**. У вас есть шанс войти в круг первых, кто строит с нами долгосрочную структуру, вырастить свой поток и закрепить место у истоков проекта.

{% hint style="info" %}
Те, кто хотят большего, идут к тем, кто может дать больше. **Garbona** — команда, которая создаёт условия для роста, пока другие только обещают.
{% endhint %}

## Почему с нами

| # | Что даём |

| **2** | Быстрые, понятные выплаты через кошелёк |
| **3** | Постоянное развитие продукта, лендинга и процессов команды |

<details>
<summary>Подробнее о команде</summary>

**Garbona** — экосистема для трафика, продукта и системного заработка. За направлениями стоит опыт: заливы, аналитика, креатив, поддержка и продукт.

Мы выстраиваем процессы так, чтобы вы фокусировались на **трафике, масштабе и деньгах**. Дизайн, связки, бот, выплаты и обновления развиваются по плану.

Соблюдайте [правила](proekt/pravila.md) — это база для всех. Актуальная редакция соглашения всегда находится в документации по адресу [https://garbona.cc/docs/](https://garbona.cc/docs/).

</details>

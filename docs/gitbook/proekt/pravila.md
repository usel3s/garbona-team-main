# Правила

{% hint style="warning" %}
Соблюдение правил обязательно для **всех** участников Garbona. Незнание не освобождает от ответственности.
{% endhint %}

## Запрещено

{% tabs %}
{% tab title="Контент и общение" %}
* Контент 18+ и любые запрещённые материалы
* Попрошайничество в любой форме

* Негативные высказывания о проекте
* Навязчивые теги, флуд и спам в адрес стаффа

{% endtab %}

## Аккаунты, логи и MaFile

| Правило | Детали |
| --- | --- |
| Валидные MaFile после вывода вещей | Становятся собственностью проекта |
| Ответственность за аккаунт / MaFile | После выдачи — на воркере |
| Доступ к логам | Через **30 минут** после залета |

{% hint style="info" %}
Не пытайтесь «забрать» то, что уже оформлено правилами проекта. Споры по логам — только в личку администрации.
{% endhint %}

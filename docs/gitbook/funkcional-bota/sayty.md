# Сайты и реферальные ссылки

Раздел бота для работы с доменами и ссылками. Доступен **только участникам команды** после одобрения заявки.

{% hint style="info" %}
Основной сценарий: **командный домен** → **Реферальная ссылка** (создание по шагам) → скопировать URL → лить трафик. Готовую ссылку открывайте **кликом по ней в списке**.
{% endhint %}

## Как открыть раздел

{% stepper %}
{% step %}
Откройте бота и нажмите **/start**.
{% endstep %}

{% step %}
В **Главном меню** выберите **Сайты**.
{% endstep %}
{% endstepper %}

На экране видно:

* сколько доменов доступно и сколько из них ваших;
* сколько человек сейчас онлайн;
* список доменов (кнопки).

У командных доменов в подписи есть метка **командный**. Также может отображаться онлайн: `example.com · командный · 3 онлайн`.

{% hint style="warning" %}
Если раздел не открывается или пишет про аккаунт сайтов — напишите администрации. Аккаунт панели привязывается автоматически; чинить вручную не нужно.
{% endhint %}

## Командный vs личный домен

{% tabs %}
{% tab title="Командный" %}
| | |
| --- | --- |
| Откуда | Даёт команда |
| Создание ссылки | Кнопка **Реферальная ссылка** |
| Список ссылок | Клик по ссылке → карточка редактирования |
| Удалить домен | Нельзя |

{% hint style="success" %}
Это основной путь для большинства воркеров.
{% endhint %}
{% endtab %}

{% tab title="Личный" %}
| | |
| --- | --- |
| Откуда | Вы добавляете сами |
| Создание ссылки | **Создать ссылку** |
| Удалить домен | Можно (**Удалить домен**) |

Подходит для своих связок и доп. адресов.
{% endtab %}
{% endtabs %}

## Создание реферальной ссылки

Кнопка **Реферальная ссылка** **всегда создаёт новую** ссылку.

{% stepper %}
{% step %}
### Откройте командный домен

**Сайты** → домен с меткой **командный**.
{% endstep %}

{% step %}
### Нажмите «Реферальная ссылка»

Бот спросит параметры по шагам.
{% endstep %}

{% step %}
### Адрес страницы

Укажите часть после домена.

```text
promo  →  50cent.me/promo
```

{% hint style="danger" %}
Если адрес уже занят — бот вернёт ошибку. Выберите другой path.
{% endhint %}
{% endstep %}

{% step %}
### Шаблон

Выберите из списка, найдите по ID или нажмите **Создать свой**.
{% endstep %}

{% step %}
### Окно авторизации

Фейк-окно / текущее / новое / About:Blank — после выбора ссылка создаётся.
{% endstep %}

{% step %}
### Скопируйте URL

В карточке ссылки URL в code-блоке. Нажмите на него в Telegram, чтобы скопировать.
{% endstep %}
{% endstepper %}

## Карточка ссылки (редактирование)

В карточке домена нажмите на строку ссылки в списке — откроется её карточка.

| Блок | Что значит |
| --- | --- |
| URL | Рабочая ссылка |
| Шаблон | Какая страница открывается |
| Окно входа | Как открывается окно авторизации |
| Сводка | Онлайн, визиты, авторизации, логи, MaFile, трейды |
| Устройства | С каких устройств заходили |

Кнопки:

* **Обновить** — свежая статистика
* **Параметры** — вкл/выкл опций
* **Шаблон** / **Окно входа** — смена настроек
* **Удалить ссылку** — удаление текущей
* **Назад** — к домену

{% hint style="info" %}
Адрес и настройки задавайте только через бота — не «собирайте» URL вручную.
{% endhint %}

## Параметры ссылки

Экран **Параметры** → переключатели **Вкл / Выкл**:

| Параметр | Зачем |
| --- | --- |
| **Встроенный вход** | Форма авторизации внутри страницы |
| **Маскировка** | Скрывает содержимое от лишних проверок |
| **Блок VPN** | Не пускать посетителей с VPN |
| **Случайный адрес** | Генерировать path автоматически |
| **Ошибка при логе** | Ошибка, если лог не прошёл |
| **Ошибка при трейде** | Ошибка при проблеме с обменом |
| **Ошибка MaFile** | Ошибка, если MaFile не принят |
| **Редирект MaFile** | После MaFile — в Steam |

### Окно входа

{% tabs %}

## Свой шаблон

В **Сайтах** → **Добавить шаблон** (или из шага создания рефералки → **Создать свой**).

{% stepper %}
{% step %}
Укажите **название** шаблона.
{% endstep %}

{% step %}
Выберите доступ: **Публичный** или **Приватный**.
{% endstep %}

{% step %}
Пришлите **HTML** текстом или файлом `.html`.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Для открытия окна авторизации на нужных элементах добавьте класс `makeAuth`:

```html
<a class="makeAuth">Войти</a>
<div class="btn makeAuth">Войти</div>
```
{% endhint %}

После создания шаблон появляется в списке при создании ссылок.

## Свой домен (опционально)

{% stepper %}
{% step %}
В **Сайтах** нажмите **Добавить домен**.
{% endstep %}

{% step %}
Отправьте домен текстом: `example.com` (без `https://` и путей).
{% endstep %}

{% step %}
Бот покажет **IP** — пропишите **A-запись** у регистратора.
{% endstep %}

{% step %}
Подтвердите **Добавить домен** → откройте домен → **Создать ссылку**.
{% endstep %}
{% endstepper %}

{% hint style="danger" %}
Удалить можно **только свой** домен. Командный удалять нельзя.
{% endhint %}

## FAQ

<details>
<summary>Где взять рефералку для залива?</summary>

**Сайты** → командный домен → **Реферальная ссылка** → пройти шаги → скопировать URL. Либо кликнуть уже созданную ссылку в списке.
</details>

<details>
<summary>Почему нет кнопки «Реферальная ссылка»?</summary>

Вы открыли **личный** домен. Рефералка есть только на доменах с меткой **командный**.
</details>

<details>
<summary>Можно ли сделать несколько ссылок на одном командном домене?</summary>

Да. Каждый раз **Реферальная ссылка** создаёт новую (свой адрес). Готовые ссылки открываются кликом по списку.
</details>

<details>
<summary>Почему статистика пустая?</summary>

Нажмите **Обновить**. Если трафика ещё не было — нули нормальны. Льйте именно URL из бота, без правок.
</details>

<details>
<summary>Нужно ли что-то настраивать перед первым заливом?</summary>

Достаточно создать рефералку с нужным шаблоном и окном. Параметры меняйте только если понимаете зачем — иначе спросите куратора / прозвон.
</details>

## Шпаргалка

```text
/start → Сайты → командный домен
       → Реферальная ссылка (адрес → шаблон → окно)
       → скопировать URL
       → список ссылок → клик = редактирование
```

# Профиты и выплаты

Как устроена экономика воркера в Garbona.

## Процент

Глобальный процент воркера задаётся администрацией и отображается в **О проекте**. Индивидуальный процент может отличаться — его видит админ в карточке участника.

{% hint style="info" %}
Актуальный % всегда смотрите в боте, а не в скринах из чата.
{% endhint %}

## Как движутся деньги

{% stepper %}
{% step %}
### Залёт / профит

Администрация начисляет профит. Бот присылает уведомление с суммой и вашей долей.
{% endstep %}

{% step %}
### Баланс

Накопленная доля попадает в доступный баланс кошелька.
{% endstep %}

{% step %}
### Заявка на вывод

Вы оформляете вывод через [кошелёк](koshelek.md).
{% endstep %}

{% step %}
### Модерация

Заявку подтверждают или отклоняют. Публичная часть процесса — в канале выплат (без нарушения [правил](../proekt/pravila.md)).
{% endstep %}
{% endstepper %}

## Профиты в боте

* Начисление делает администрация.
* Доступны сводки и история (раздел профитов / кошелёк — по актуальному меню).
* При начислении приходит уведомление.

## О проекте (цифры)

В меню **О проекте** можно увидеть:

| Показатель | Зачем |
| --- | --- |
| Дата открытия команды | Контекст проекта |
| Сумма и число профитов | Общая динамика |
| Процент выплат воркеру | Ваша экономика |

{% hint style="warning" %}
За вывод средств с панели может взиматься комиссия (комиссия маркета и пр.). Условия — в [правилах](../proekt/pravila.md).
{% endhint %}

{% hint style="success" %}
Прозрачность = меньше споров. Если сумма или статус непонятны — пишите [@karma_ceo](https://t.me/karma_ceo) в личку, не в общий чат.
{% endhint %}

<details>
<summary>Почему доля меньше «ожидаемой»?</summary>

Проверьте процент, комиссии и тип начисления. Скрин из чата не заменяет данные в боте. Разбор — только в личку админу.

</details>

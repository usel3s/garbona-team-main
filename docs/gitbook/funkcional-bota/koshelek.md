# Профиль и кошелёк

Разделы бота для участника команды.

## Профиль

В профиле отображаются ваши данные, настройки и связанные действия (включая анонимность в топах — если доступно в вашей сборке бота).

{% hint style="info" %}
Меняйте чувствительные данные только осознанно. Ошибки в реквизитах задерживают выплаты.
{% endhint %}

## Кошелёк

Кошелёк показывает доступный баланс для вывода.

{% stepper %}
{% step %}
### Откройте кошелёк

Главное меню → **Кошелёк**.
{% endstep %}

{% step %}
### Проверьте сумму

Минимальный порог вывода задаётся проектом (ориентир — от **$1**, актуальное значение смотрите в боте).
{% endstep %}

{% step %}
### Создайте заявку

Выберите сеть / метод. В боте сразу видны **комиссия сети** и **сумма к выплате**.
{% endstep %}

{% step %}
### Дождитесь модерации

При необходимости администрация запросит дополнительные данные или ссылку на выплату.
{% endstep %}
{% endstepper %}

## Важно

{% tabs %}
{% tab title="Не делайте" %}
* Дублирующие заявки на вывод
* Смену реквизитов «на лету» без сообщения админу
* Обсуждение статусов в общем чате
{% endtab %}

{% tab title="Делайте" %}
* Один вывод — одна заявка
* Следите за статусом в боте и канале выплат
* Вопросы — [@karma_ceo](https://t.me/karma_ceo) в личку
{% endtab %}
{% endtabs %}

{% hint style="warning" %}
За вывод с панели также может взиматься комиссия маркета — см. [правила](../proekt/pravila.md).
{% endhint %}

<details>
<summary>Заявку отклонили</summary>

</details>

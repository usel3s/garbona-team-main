# Старт и заявка

Как попасть в команду через бота **Garbona**.

{% hint style="info" %}
Перед заявкой обязательно примите [правила](../proekt/pravila.md). Без согласия заявка не принимается.
{% endhint %}

## Пошагово

{% stepper %}
{% step %}
### Запуск бота

Откройте бота Garbona в Telegram и нажмите **/start** (или кнопку старта).
{% endstep %}

{% step %}
### Правила

В меню найдите подачу заявки / правила. Прочитайте запреты и блок обратной связи. Подтвердите согласие.
{% endstep %}

{% step %}
### Анкета

Ответьте на вопросы формы честно и по делу. Чем яснее опыт и источники трафика — тем проще модерации принять решение.
{% endstep %}

{% step %}
### Ожидание решения

Заявка уходит администрации. После одобрения вы становитесь участником команды и получаете доступ к рабочему чату и разделу выплат. Все руководства остаются доступны только по адресу [https://garbona.cc/docs/](https://garbona.cc/docs/).
{% endstep %}
{% endstepper %}

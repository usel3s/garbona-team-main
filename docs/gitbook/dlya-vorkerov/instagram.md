# Instagram

Instagram — один из сильных источников целевого трафика.

{% hint style="info" %}
Фундамент: чистый IP, аккуратный прогрев и ежедневный контент. Успех строится на системности, а не на «магических» алгоритмах.
{% endhint %}

## Сценарий

{% stepper %}
{% step %}
### Инфраструктура

* **IP:** чистые VPN (AdGuard, NordVPN, Windscribe) или статические / мобильные прокси.
* На мобиле для прокси удобны Tun2Socks и похожие клиенты.
* **Регистрация:**
  * Email — только с максимально чистым IP.
  * Телефон — устойчивее; SMS: SmsHub, SmsActivate.
{% endstep %}

{% step %}
### Стратегия контента (Reels)

Каждый ролик:

1. Сильный [хук](khuki.md) в первые секунды.
2. Описание **выше** хештегов + CTA.
3. Релевантные теги без прямого триггера, если аккаунт «белый».
{% endstep %}

{% step %}
### Методы работы

{% tabs %}
{% tab title="Аккаунты с историей" %}
* 180+ дней.
* Лёгкий прогрев: 5–7 тематических подписок → пауза ~20 мин → постинг.
* Массовый запуск пула с одним крео повышает шанс в рекомендации.
{% endtab %}

{% tab title="Самореги" %}
1. Регистрация на одном устройстве.
2. Вход с другого чистого устройства.
3. Пауза ~24 ч → пост → ещё 24 ч → отбор живых.
{% endtab %}
{% endtabs %}
{% endstep %}

{% step %}
### Воронка «кодовое слово + Direct»

1. В ролике: «напиши в Direct слово **BONUS**».
2. Закрепленный комментарий дублирует условие.
3. В Direct — ссылка на оффер / канал.

Плюсы: фильтрация аудитории, рост вовлечённости, меньше прямых ссылок в описании.
{% endstep %}

{% step %}
### Масштаб

Менеджеры аккаунтов — для пула, автопостинга и автоответов. Лимиты и задержки держите «живыми».
{% endstep %}

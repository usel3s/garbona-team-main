# Клоакинг

**Клоакинг (Cloaking)** — показ разного контента по одному URL: целевой аудитории — оффер, проверяющим — «белая» страница.

{% hint style="warning" %}
Мануал для ознакомления. Ответственность за соблюдение правил рекламных сетей и законов юрисдикции — на воркере. В Garbona запрещена реклама сторонних проектов в наших чатах — см. [правила](../proekt/pravila.md).
{% endhint %}

## Как это работает

{% stepper %}
{% step %}
Пользователь переходит по ссылке.
{% endstep %}

{% step %}
Сервер анализирует IP, UA, язык, cookies и др.
{% endstep %}

{% step %}
Решение:

* **Целевой** → money / оффер
* **Проверяющий** → white / safe page
{% endstep %}
{% endstepper %}

## Зачем

* Снижение риска бана кабинетов при чувствительных офферах.
* Показ релевантной «белой» версии модераторам.
* Защита доменов и связок.

## Компоненты

| # | Компонент |
| --- | --- |
| 1 | ПО клоака: JustCloak, Adspect, Cloaking.House или кастом |
| 2 | Два лендинга: качественный white + money page |
| 3 | Домены / хостинг: лучше раздельно; white без истории банов |
| 4 | Антидетект / прокси — для проверки сценариев |

## Базовая настройка

{% stepper %}
{% step %}
Купите домены, поднимите хостинг/VPS, установите скрипт клоака, залейте white и money.
{% endstep %}

{% step %}
В панели настройте whitelist / blacklist IP и логику:

* blacklist / датацентры рекламных сетей → white;
* целевая страна + не blacklist → money;
* остальное → white или 404.
{% endstep %}

{% step %}
В объявлении указывайте URL **клоака**, не прямой оффер. Протестируйте:

{% tabs %}
{% tab title="Как модератор" %}
DC IP → только white.
{% endtab %}

{% tab title="Как юзер" %}
Целевое ГЕО → money.
{% endtab %}
{% endtabs %}
{% endstep %}
{% endstepper %}

## Типичные ошибки

<details>
<summary>Что чаще всего ломает связку</summary>

* Общие аналитические счётчики на white и money.
* Пустой / шаблонный white.
* Примитивный `.htaccess` редирект без фильтрации.
* Устаревшие IP-базы blacklist.
* Трафик из нецелевых ГЕО на money.

</details>

{% hint style="danger" %}
Не обсуждайте чужие клоак-сервисы и офферы в чатах Garbona — это нарушение [правил](../proekt/pravila.md).
{% endhint %}

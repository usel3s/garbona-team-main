# YouTube

Мануал по работе с **YouTube Shorts**.

{% hint style="info" %}
Shorts — вертикальные ролики до **60 секунд** (формат **9:16**). Заголовок до 100 символов. Возрастные ограничения настраивайте корректно.
{% endhint %}

{% hint style="success" %}
Сначала подготовьте устройство — [device setup](podgotovka-ustroistva.md).
{% endhint %}

## Сценарий

{% stepper %}
{% step %}
### Подготовка устройства

* Полный сброс устройства (по возможности).
* Регион **USA**, язык **English** (iOS и Android).
* Стабильный VPN / прокси целевого ГЕО.
* Опционально: аккаунты YouTube с историей (возраст повышает траст).
{% endstep %}

{% step %}
### Аккаунт и оформление

* Регистрация: телефон (виртуальный номер) или Gmail.
* Аватар и описание канала — тематические, с мотивацией к действию.
{% endstep %}

{% step %}
### Прогрев (2–3 дня)

По 20–60 минут в день: рекомендации, лайки, просмотры близкой тематики. Без шаблонных «ботовых» паттернов по времени.
{% endstep %}

{% step %}
### Креативы

* Лучше уникальный контент, не копия уже залитых Shorts.
* Допустима адаптация **без чужих watermark** + уникализация.
* Сильный CTA: «подробнее в описании / Telegram».

См. также: [hooks](khuki.md), [creatives](kreativy.md).
{% endstep %}

{% step %}
### Продвижение и загрузка

{% tabs %}
{% tab title="Мобильно" %}
`+` → Create Shorts.
{% endtab %}

{% tab title="ПК" %}
YouTube Studio → Создать → загрузка файла + `#Shorts`.
{% endtab %}
{% endtabs %}

* Регулярные публикации (можно планировать в Studio).
* SEO: ключи в заголовке и описании.
* Обязательный тег **#Shorts**.
* Доступ: открытый + возрастные ограничения.
{% endstep %}
{% endstepper %}

## Итог

После настройки Shorts даёт условно-пассивный поток при регулярных публикациях. Держите качество креатива и CTA — остальное масштабируется системностью.

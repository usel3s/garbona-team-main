# Креативы

Кратко: форматы крео, описания, теги и био под пролив. Шаблоны помогают стартовать, уникальность масштабирует.

{% hint style="info" %}
Чёрная полоса (баны, нет рег/деп) бывает у всех. Терпение и тесты бьют «магический» один крео.
{% endhint %}

## Базовые схемы

{% tabs %}
{% tab title="Пример 1" %}

2. **Далее** — регистрация → промо → игровой процесс (Plinko, Mines, Aviamasters и т.п.).
{% endtab %}

{% tab title="Пример 2" %}
1. **Перебивка** — мотивационный визуал.
2. **Переход** — регистрация / промо / геймплей.

{% endtabs %}

Идей много: ищите тренды и делайте свои вариации. Исходники — Kick, YouTube, Instagram, стоки. Хуки — в [hooks](khuki.md).

## Описание, теги, био

{% stepper %}
{% step %}
### Описание

Коротко, можно с эмодзи. Избегайте жёстких триггеров в «белых» аккаунтах (`casino`, `free money`, прямые домены).

Примеры:

* `Promo in bio`
* `Link in bio`
* `Get the promo in my profile`
{% endstep %}

{% step %}
### Теги

Микс трендовых и тематических. Примеры направлений: `#reels` `#money` `#bitcoin` `#win` — подбирайте под ГЕО и риск аккаунта.
{% endstep %}

{% step %}
### Био

```text
Enter the promo code - YOURPROMO
Get your bonus in one click
```

Домены с точкой в био часто режут — пишите `example com` или используйте отдельное поле ссылки:

```text
example.com/?promo=YOURPROMO
```
{% endstep %}
{% endstepper %}

# Хуки

Хук — одна из ключевых частей креатива. Он удерживает внимание и повышает досмотр ролика.

{% hint style="info" %}
Сборник идей: [transitionalhooks.com](https://transitionalhooks.com/)
{% endhint %}

## Что такое хук

**Хук** — первые **1–3 секунды** ролика. Задача: остановить скролл и создать интригу.

| Тип | Задача |
| --- | --- |
| **Hook** | Удержание в начале |
| **Transition hook** | Удержание в середине при смене сцен |

Эффект:

1. **Алгоритм** — высокий retention в начале → больше охвата.
2. **Психология** — вопрос / эмоция, которую хочется «закрыть» досмотром.

## Категории для гемблинг / casino-креативов

{% tabs %}
{% tab title="Визуал и эмоция" %}
* Роскошь: часы, фишки, шампанское, эмоция победы.
* Текст: «Как превратить $100 в $10 000 за вечер?»
* Драма: напряжение у экрана → «Ошибка, из-за которой я терял деньги каждый день».
{% endtab %}

{% tab title="Вопрос / провокация" %}
* «Почему вам лгут, что это просто удача?»
* Сплит-экран: скука vs азарт — «выбор очевиден».
{% endtab %}

{% tab title="Секрет и ценность" %}
* Схемы / график роста: «Тактика, о которой молчат».
* Разрушение мифа: «Главный миф о блэкджеке…».
{% endtab %}

{% tab title="Соцдоказательство" %}
* Скрин вывода (без персональных данных).
* Таймер / срочность бонуса.
{% endtab %}
{% endtabs %}

## Где брать идеи

1. Топ роликов ниши на целевом языке (Shorts / Reels / TikTok).
2. Смежные ниши: финансы, крипта, мотивация.
3. Приёмы из трейлеров кино.

## Техправила

{% hint style="success" %}
* 0.5–1 с — максимально яркий кадр.
* 1–3 с — визуал + текст/озвучка уже дают смысл.
* Звук обязателен.
* Текст на экране короткий, контрастный, крупный.
* Эмоция сразу: любопытство, FOMO, азарт, «секрет».
{% endhint %}
